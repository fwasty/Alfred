# Local Business Automation Audit — Lead Scoring (Carrollton TX + 30mi)

## Goal
Prioritize businesses by **upgrade opportunity** for the wedge offer:
**Lead Rescue + Review Engine** (missed-call text-back + follow-up + review requests + simple landing upgrade).

## Tiers
- **HIGH**: big leaks (no site / broken funnel / neglected GBP)
- **MID**: decent presence, weak conversion + weak automation signals
- **LOW**: already strong funnel/booking/chat + strong brand/ops (skip or only sell premium)

## Scoring (0–15)
### A) Web presence (0–5)
- 0: no site / broken
- 1–2: outdated/slow/confusing, weak mobile
- 3: decent but weak CTA
- 4–5: modern, clear CTA, fast

### B) Conversion path (0–5)
Check: booking/quote form, click-to-call, chat, clear CTA, form quality.

### C) Automation/reputation signals (0–5)
Check: GBP completeness, review volume/recency, replies, "text us" / reminders / intake.

## Lead record fields
- Name
- Industry
- City
- Website
- Google Maps link
- Tier (HIGH/MID/LOW)
- Score (A+B+C)
- Reasons (3 bullets)
- Best pitch angle (1 line)
- Outreach channel (email/form/IG/phone)
